Apparently, this project doesn't have a ReadMe file so I have to rely on my memory. It all started when I saw a social media post about a female dev created a browser extension where in every new tab, the program will generate a quote and it'll be displayed in the browser's homepage.

In her concept, it acts like a flashcard if you want to memorize something but in your browser.

Then, I made this very simple project to do the same thing but the difference is that its a webpage, and it has Christian quotes.

The repository was created on Mar 1, 2023, but I don't think that's the exact date I've created it. Anyway, the link to the repository and the preview webisite are down below if you want to check them out.
